🙌 So, is it really the ideal solution? 🙌

  • 🧑‍💻 IDE as code 😎
  • 🐳 Requires some knowledge of containers
  • 🪫 Requires a machine with enough RAM and disk space (even with optimized images)
  • 🔌 Offline mode may be impossible (if the images are not built beforehand)
  • 🐛 Possible issues with the development environment rather than with the code
  • 😭 Integration in IntelliJ IDEA (Ultimate)
