Démos

🙌 Alors, c’est vraiment la solution idéale ? 🙌

  • 🧑‍💻 IDE as code 😎
  • 🐳 Nécessite des connaissances en conteneurisation
  • 🪫 Nécessite une machine avec de la RAM et de l’espace disque (même en optimisant les images)
  • 🔌 Mode offline potentiellement impossible (si les images ne sont pas construites)
  • 🐛 Problèmes potentiels sur l’environnement de développement et non sur le code
  • 😭 Intégration dans IntelliJ IDEA (Ultimate)
